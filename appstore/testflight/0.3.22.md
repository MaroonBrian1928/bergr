New in 0.3.22

- Smoother and cooler chats on iPhone: the working animations (the mark beside "Thinking…", the shimmer, the list spinner) run in Core Animation instead of redrawing the chat every frame, and stop when off screen.
- The Agents list no longer rebuilds while a chat covers it, and the chat no longer draws itself offscreen on every scroll frame.
- Answering a menu from the chat (like Claude's "trust this folder") picks the option you tapped: keys can no longer arrive out of order.

What to Test
- Leave a chat open while Claude works for a few minutes: the phone should stay cool, scrolling smooth.
- Start a new Claude session in a folder it hasn't seen and tap Yes on the trust question: it should start.
- Check the spinner turns clockwise and the "Thinking…" mark looks right.
