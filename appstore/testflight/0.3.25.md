New in 0.3.25

- Auto mode blocks: when Claude's auto mode blocks a command, the chat shows it with an Allow and Retry button, and the finished notification says a command was blocked.
- Menus: a Claude or Codex menu opened with a slash command (/model, /resume, /mcp, /permissions…) shows as a card with its options and a Close button. Sending a message while a menu is open closes it first instead of typing into it.
- Codex: /clear sent from the chat now starts the new chat.
- Fixed: the build that doesn't get notifications no longer uninstalls the push helper from your machines.

What to Test
- In a Claude chat in auto mode, when a command gets blocked, tap Allow and Retry: it should run.
- Type /model in a chat: the card should show the models; pick one, or Close.
- Send /clear to a Codex chat: the chat should start over.
- Settings > Helpers: update machines to helper 26.
