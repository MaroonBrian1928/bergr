New in 0.3.20

- herdr-core updates: when a machine runs an older herdr-core than the latest release, a banner offers to update it, in its chats and in the Agents list. One tap updates it; your terminals keep running. "What's new" shows the release notes.
- Shell in New Session: start a plain terminal next to Claude Code, Codex and Antigravity. On a machine with no agents installed, Shell is picked for you.
- New Session no longer gets stuck with Start doing nothing after switching between machines.

What to Test
- On a machine with an older herdr-core, check the update banner shows in a chat and the Agents list, tap Update, and check the banner goes away once it reconnects.
- Tap × on the banner and check it stays hidden until the next release.
- In New Session, pick Shell and start one; check it opens a normal terminal in the chosen folder.
- Switch between machines in New Session and check Start always starts something.
