New in 0.3.18

- Background commands: commands an agent leaves running (Claude and Codex) show in the chat with how long they've run; tap one for its latest output. The Agents list says how many are running in the background.
- What's it doing: working agents get a short line in the Agents list describing what they're doing, written on your device by Apple Intelligence. Long-press an agent and choose "What's It Doing?" for a few sentences and its latest steps.
- Machines added both directly and through another machine ("via") now show once, using the direct connection. The "via" copy comes back if the direct one fails. Matching uses the address, port and user, and looks names up to their IP.
- No more double notifications when a machine's helper is already sending them.
- Questions: long questions that wrapped in the terminal read as one, and each option's description shows under it.
- Chat: Claude's short thinking updates between steps now show, and a running step no longer shows the previous step's output.

What to test
- Have an agent run something in the background (a long build or a sleep). Check the time counts up, the output opens with a tap, and it turns to a check when done.
- Watch the Agents list while an agent works, and try "What's It Doing?".
- If a machine is both added directly and linked through another, check it shows once, and reappears "via" if you stop the direct one.
- With helper notifications on and Bergr open, check each alert arrives once.
