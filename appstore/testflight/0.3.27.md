Chat shows when it has submitted a shell command and is waiting for the result. It no longer offers to resend the command while Codex is catching up. Finished tools clear their running indicator even when they return no output.

What to test
Run a shell command from chat that takes a few seconds. Confirm that the command appears right away and that chat does not offer to send it again. Run a Codex tool command that produces no output and check that it stops showing as running when it finishes.
