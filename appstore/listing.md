## Description (4000)

Bergr puts the coding agents running on your computers in your pocket.

It connects to your machines over SSH and shows every agent that herdr runs there, on all of them at
once: which are working, which are done, and which need you. Open one and you get its conversation
as a chat, with a real terminal underneath whenever you want it.

EVERY AGENT AT A GLANCE
• One list across your machines, sorted by what needs you, or grouped by machine
• Works with Claude Code, Codex and Antigravity, and their sub-agents
• Machines linked through another machine show up too

A CHAT FOR EACH AGENT
• Replies stream in as the agent writes them, with tool runs, plans and images
• Reply, paste a screenshot, or queue a message while it works, or send it now
• Slash commands, skills and ! shell commands
• Switch the model, effort and permission mode, and see how full the context is

ANSWER IN ONE TAP
• An agent's question or approval becomes buttons: in the chat, on the Lock Screen and in the
  Dynamic Island

STAYS WITH YOU
• A Live Activity and a Home Screen widget
• Optional push alerts when an agent finishes or needs you, end-to-end encrypted: the relay that
  delivers them can't read them

A REAL TERMINAL
• Powered by Ghostty's libghostty-vt: key bar, hardware keyboards, links, scrollback, pinch to zoom

SECURE BY DESIGN
• SSH keys live in the Secure Enclave, optionally behind Face ID, or import your own
• Host keys are checked on every connect
• No account, no tracking

On iPad and the unfolded iPhone Duo, your agents sit beside the conversation, and a second
conversation can open next to the first. Bergr also runs on Apple silicon Macs.

Try it right away with the built-in demo machine, no server needed. To use it with your own
computers, install herdr (https://github.com/herdrdev/herdr) on them.
