Chat now follows Claude Code sessions running in Code Mode. Each script Claude runs shows as one Script row, with its output attached once it finishes. Restarting Claude from chat also turns transcript saving back on when the session had inherited it switched off.

What to test
Start Claude with CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 and ask it to do something that runs commands. Check that Script rows appear in chat with their descriptions and that their output fills in. In a session showing "Transcript saving is off", use Restart from chat and check that the conversation appears in chat afterwards.
