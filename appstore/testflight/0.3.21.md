New in 0.3.21

- Restart in a chat now opens the restarted Claude Code instead of leaving "Terminal is gone", and the update banner no longer keeps asking after you've updated.
- Changes on the Mac (and phone) show the repository the agent is working in, even when the terminal started in your home folder.
- Last turn snapshots are taken in the agent's working folder (push helper 25: tap Update on each machine).
- The model list offers Fable 5.2.
- On-device summaries stick to what the diff shows instead of repeating example sentences.
