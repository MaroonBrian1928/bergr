## Description (4000)

Bergr is the shepherd for your agent herd.

Your coding agents run in terminals on your own machines. Bergr is a native app for iPhone, iPad and Mac that watches all of them, shows which ones need you, and lets you answer in a tap. Apple Intelligence, running on your device, does the reading for you.

ON-DEVICE INTELLIGENCE
• Long tool output becomes a one-line summary in the chat. The full output stays a tap away
• Reply suggestions when an agent finishes a turn. Tap one to fill the reply field
• A plain sentence on what a risky command would do, before you approve it
• Conversation titles, a summary of what an agent changed, and a "While you were away" digest
• Alerts written as one sentence about what happened, when Bergr itself is watching
• Written by Apple's on-device model. The text never leaves your device
• Needs Apple Intelligence. Without it, Bergr works the same, without the summaries

ANSWER WITHOUT TYPING
• Permission prompts from Claude Code and Codex become buttons in the chat and on notifications
• While Bergr stays running, the same buttons are on the Lock Screen and in the Dynamic Island
• Codex's questions are answered from the chat, with a tap or a typed reply
• "Always allow" rules for commands you trust, scoped to one machine and project folder
• Risky commands always ask. Every answer is kept in the conversation

EVERY AGENT AT A GLANCE
• One list across your machines, sorted by what needs you or grouped by machine
• Works with Claude Code, Codex and Antigravity, and counts their sub-agents
• A chat for each agent: replies as they stream in, tool runs, plans and images
• Switch the model, effort and permission mode from the chat

KNOW YOUR LIMITS
• Context window and plan usage for every running agent, per session and per week
• History charts for the last 24 hours or 7 days, with resets marked
• A forecast: "At this rate you'll hit the limit at 15:10"
• A Usage widget, and an alert before a plan limit or a full context window

SAY IT, SNAP IT, PASTE IT
• Dictate a reply. It stops when you pause
• Take a photo, scan a document, or paste an image from the clipboard into a reply
• Ask Siri what needs you, send a message to an agent, or hear its latest reply
• Queue a reply while the agent works. Slash commands, skills and ! shell commands

STAYS WITH YOU
• A Live Activity, Home Screen and Lock Screen widgets, and a Control Center button
• Optional push alerts from a small helper Bergr installs on your Mac, Linux or Windows machines
• Alerts are end-to-end encrypted. The relay that delivers them can't read them
• Focus filters, quiet hours and muted agents
• An alert when a working agent goes quiet, and a reminder when a question is still waiting

SEE THE WORK
• Changes: git status, a diff per file and the last test run
• Start a session in a new git worktree, and remove it when the session ends
• Search past conversations and open the files an agent mentions
• Machine health: load, memory, disk, battery

A REAL TERMINAL
• Under every chat, powered by Ghostty: key bar, hardware keyboards, links, scrollback, pinch to zoom

PRIVATE AND SECURE
• Bergr talks to your machines over SSH. No account, no tracking
• SSH keys live in the Secure Enclave, optionally behind Face ID, or import your own
• Host keys are checked on every connect

On iPad and the unfolded iPhone Duo, your agents sit beside the conversation, and a second conversation can open next to the first. Bergr also runs on Apple silicon Macs.

Try it with the built-in demo machine, no server needed. To use it with your own computers, install herdr (https://github.com/herdrdev/herdr) on them.
